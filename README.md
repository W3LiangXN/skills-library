# skills-library

用于管理和分发 Codex Skills。

## 已有 Skill

- [`meowgic-openapi-to-api-method`](./meowgic-openapi-to-api-method)：将 OpenAPI、Apifox 或 Swagger 文本转换为 Meowgic 项目的 TypeScript service 类型与 API 方法。

## 安装

发布到 GitHub 后，可以通过 Skills CLI 安装：

```bash
npx skills@latest add W3LiangXN/skills-library
```

也可以按 CLI 支持的仓库路径或 Skill 名称进行安装。
